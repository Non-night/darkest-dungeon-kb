.gain_loot
# 分类
扩展/专项字段
# 参数类型
单个字符串（战利品表 ID；文档示例带引号）
# 参数约束
- 参数为战利品表 ID 字符串；原文写法为 `.gain_loot "example_loot_table_id"`，不是物品 ID 或装备饰品 ID。
# 固定值 / 参数候选
- 无固定候选表；按下方参数说明填写。
# 语义
- 战斗中触发时，从所指定的 loot table 掷取战后战利品。
- 战斗外不会触发；不要将本字段解释为立即向背包发放物品。
# 作用范围
- Effect 参数，目标仍按调用方与 `.target` 共同确定；文档未指定额外强制目标类型。
- 只在战斗内触发；其产出属于战后战利品。
