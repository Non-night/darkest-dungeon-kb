# 语义
- `item ID`：调用物品 ID 的同名 Effect，不消耗物品；可触发怪癖为该物品设置的效果替代或道具式进化。
- 怪癖改变使用效果或触发道具式进化时，不执行道具原 Effect；套娃中此类替代须位于链尾。
- 原表第120条 P1862–P1863/X2385–X2387记载，一次使用道具（包括道具套娃中的虚拟道具）不会在同一次使用中连续完成 A→B→C 这类多级怪癖进化；仅为该单次使用范围的历史观察。当前用户于2026-11-05确认记录，非新增游戏实测。详见 Mechanics/62-item套娃与连续调用限制.md。
- 原表第120条 P1864/X2389另记载：两个怪癖都要求同一道具进化时，单次使用只会进化其中一个；此处不据此补推具体选择顺序。当前用户于2026-11-05确认按此范围记录，非新增游戏实测。详见 Mechanics/62-item套娃与连续调用限制.md。
- 原表第120条 P1865/X2390记载：多个怪癖要求同一道具进化时，优先进化列表位置靠上的怪癖；进化后的怪癖移至列表最下端。仅记录该排序观察，不外推其他怪癖排序场景。当前用户于2026-11-05确认记录，非新增游戏实测。详见 Mechanics/62-item套娃与连续调用限制.md。
- 原表第120条 P1866/X2391另记载：重启读档时红钩会根据怪癖 ID 首字母重新排序所有怪癖；当前用户补充确认，该重排优先级低于原生自带锁定和已经手动锁定的怪癖，不能越过锁定状态。仅记录该历史观察及锁定边界，不外推其他排序或锁定机制。详见 Mechanics/62-item套娃与连续调用限制.md。
- 原表第120条 P1867/X2393记载：两个怪癖都改变同一个道具的使用效果时，单次使用会同时触发两个改变后的效果。仅限多个怪癖对同一道具效果作替代的场景，不与道具式进化规则混同；当前用户于2026-11-05确认按此边界记录，非新增游戏实测。详见 Mechanics/62-item套娃与连续调用限制.md。
- 原表第120条 P1868/X2395进一步记载：若一个怪癖改变道具使用效果、另一个怪癖要求使用该道具进化，且两者同时存在，则使用该道具时只进行道具式进化，改变使用效果的怪癖不触发；道具式进化优先于效果替代。仅限该二者冲突场景，不与两个效果替代同时触发的规则混同；当前用户于2026-11-05确认按此边界记录，非新增游戏实测。详见 Mechanics/62-item套娃与连续调用限制.md。
- 正常执行时实际使用者为当前英雄，即使下一层以其他英雄为目标，也不是各目标英雄使用道具。
- 技能内调用须前置解晕且不结束回合；挂起后可能顺延给后面的英雄。恢复门槛是下一次行动还是下一次可自由行动，当前未知，不保证精确接手英雄。
- 不结束回合技能可借虚拟道具触发怪癖瞬间进化；仅修改进化时间 Buff 不能代替这一调用。
# 作用范围
- Effect 定义行；实际作用对象由调用方目标与 `.target` 等字段共同决定。
- 可能被技能、饰品触发器、ActorDot、spawn、hp_reaction、奇物等系统引用。
# 引擎行为（重要）
- 原版确认：游戏本体或官方 DLC 的 effect 定义直接使用该字段。
- 一个 item Effect 可调用另一个 item Effect，形成连续、有间隔的道具套娃。真实道具无需额外前置解晕或不结束回合检查，但非最后一层不得用负 `.initiative_change` 结束自身回合，否则后续层可失效、顺延甚至黑屏。
- 原表第14条 P486 记载多人调用按目标数产生待执行 item，曾观察到 ESC 后继续及本进程不再报错；P487 又笼统称崩溃。这些历史观察与解释不能作为 ESC 恢复保证。
- 当前用户2026-11-02不能确定群体调用的崩溃条件，记忆最后层对群崩溃仅为待核线索。具体出错层级及结果未知；撤销最后层可安全对群的旧保证，避免依赖群体套娃。详见 Mechanics/62-item套娃与连续调用限制.md。
- 社区资料另记：怪物没有道具系统，怪物侧使用会黑屏报错并终止相关技能或效果；原资料曾观察 ESC 后可继续及本进程不再黑屏，此为怪物调用场景的历史观察，不是稳定恢复承诺。
- 风灵月影无限道具作弊会导致道具套娃出现无限翻滚 BUG。
- 社区资料记录该执行序列间隔很长，战斗外可由游戏玩家鼠标点选英雄改变后续 Effect 发起者；不据此推断战斗内挂起恢复门槛。
# 常见错误
- 把字段已收录或格式看似正确误当成“引擎行为已验证”。
- 忽略调用方目标、queue、apply_once、死亡/回合外时序等上下文。
