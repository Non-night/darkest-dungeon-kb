.daze
# 分类
扩展/专项字段
# 参数类型
单个数值（整数、小数或带 `%` 的数值）
# 参数约束
- `.daze <duration>` 施加迷乱（官方译名“晕眩”，亦称“小晕”），数值表示持续时间，不是数字布尔；`.daze 1` 的 1 可提高，`.daze 0` 不构成有效 daze 技能标志。
# 固定值 / 参数候选
- 无固定候选表；按下方参数说明填写。
# 语义
- 新版施加迷乱时不重排行动队列；在目标个人回合开始时触发，将该次行动移至本整轮末尾，不等于把目标所有行动立即一起移后。
- 知识库编写者于2026-11-05确认：处于 daze（迷乱）状态的单位触发反击时，会提前触发并结算原本在个人回合开始时处理的行动延后效果；不能再把正常个人回合开始视为唯一触发入口。
- 本次确认只补充反击会提前触发并结算 daze；反击是否取消、是否消耗正常行动、状态清除方式及多行动点的具体处理均未在本次说明，不据此扩展；也不推广到其他回合外调用。
- 施加率使用施术者的眩晕施加率，并检查目标眩晕抗性；`.undaze 1` 可以清除迷乱。
- `dazed` 可作为 `keyStatus`，包括 Buff 的 `actorStatus` Rule。
- 眩晕自动清除迷乱；已经眩晕的目标免疫迷乱。再次迷乱已迷乱的目标不会自动升级为眩晕，需由 Mod 自行实现。
# 作用范围
- 来自屠夫竞技场的机制；新版不再按旧版单机部分失效限制使用。
# 引擎行为（重要）
- 原版扫描未找到直接实例；代码案例来自 Mod，但下方行为来自已收录的专项资料或实测结论，不以 Mod 案例单独作为引擎结论。
- 新版：施加时不重排，个人回合开始延后本次行动；反击会提前触发并结算这一延后效果（知识库编写者2026-11-05确认）；眩晕清除迷乱且免疫迷乱，重复迷乱不自动升级。不再要求额外Daze动画；但新版仍有已测卡死组合：技能直接引用、均queue true且先daze后stun。不得概括为组合崩溃已全部修复；其他时序按2026-11-07对照结果核对。
- 详见：[Mechanics/19-Effect性质不够确定.md](../../Mechanics/19-Effect性质不够确定.md)
- 新版不再沿用“单机部分失效”及额外Daze动画依赖的旧限制；但.stun／.daze组合卡死未完全修复，须继续遵守后续2026-11-07对照测试的具体时序边界。不能把旧动画要求撤销理解成全部组合安全。
- 迂回表第128条 P1936/P1937（X2491/X2492）记录了 2026-11-05 更新之前的历史观察：未安装屠夫竞技场 DLC 且没有其他 Mod 提供 daze 动画时，实际施加 daze 可能立即崩溃；同一时序内即使先用 unstun，再施加 daze 与 stun，旧版组合仍可能崩溃。该记录不覆盖新版判断；P1934/X2489 的双false虚假禁用标志物用途仍可按现行规则使用。
- 迂回表第129–130条的指定段落（P1940/P1941–P1942、P1946–P1947、P1998–P2007、P2024–P2027；X2497/X2498–X2499、X2503–X2504、X2568–X2581、X2607–X2610）记录了 2026-11-05 更新之前的历史观察：旧版单机对英雄的 daze 可能只有动画效果，对怪物可能仅在施加后的第一整轮产生行动延后；先让动画稳定再施加另一状态与同一时序内同时成功施加的结果不同，后者会导致 stun+daze 卡死；同一时序内前置或同层解除眩晕可能无效，而特定 `queue false` 的 stun、`queue true` 且早于 daze 的 unstun 曾被记录为可规避；没有 daze 动画资源时实际施加可能崩溃。原表还记录 ActorDot 中 daze 的旧版先行时序可能绕过普通前置代码，因而无法用同样方法稳定规避。以上均保留为旧版历史观察，不覆盖新版判断，也不将该旧方案推广为当前安全模板。
- 当前用户于2026-11-05根据新版状态互斥与清除说明判断：旧版那种“Daze 与眩晕只要同技能／同组合出现就必然触发旧崩溃”的普遍规则不再沿用，也不再要求额外准备 Daze 动画素材；但这不等于新版所有 Daze／眩晕时序组合都安全，也不代表两状态可同时保留。
- 当前用户于2026-11-07转述外部来源作者无夜的攻击技能实测：两个目标 Effect 都为 `queue true` 时，先施加眩晕、后施加迷乱可以正常结束回合；先施加迷乱、后施加眩晕会使回合卡死。将迷乱改为 `queue false`、眩晕保持 `queue true` 时，本次测试正常。上述三项均为技能直接引用 Effect、目标为攻击目标的结果。
- 当前用户补充：测试 Mod 中，AWR 自附魔（Rule 为 `always`）引出的 `queue true` 眩晕，加上技能 `queue false` 迷乱，在目标原本没有迷乱时测试正常；但当前用户曾观察到目标已有 `daze` 时，先由技能 `queue false` 再由 AWR 自附魔的 `queue true` 施加眩晕后回合卡死，正在尝试复现。因此“已有 daze 状态”是否为必要条件、AWR 自附魔是否改变该边界，以及该现象是否稳定，均暂未确认。
- 旧有技能属性标签用途保留：即使正值 `.daze` 因概率、命中条件等未实际施加，仍可配合 `disable_combat_skill_attribute/daze` 检查技能属性；`.daze 0` 不构成该标签。
# 常见错误
- 将持续时间误写成布尔开关。
- 认为重复迷乱自动升级为眩晕。
- 将个人回合开始延后本次行动误解为施加时立即重排目标全部行动。
