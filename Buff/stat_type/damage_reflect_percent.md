damage_reflect_percent
# 分类
Buff `stat_type`
# 参数类型
固定字符串；配套 `amount` 为数值，`stat_sub_type` 为字符串。
# 参数约束
- 该类型没有副类型；JSON 中字段仍必须存在，并写为空字符串 `""`。
- 可用 rule 分类仍应结合具体 stat_sub_type 和引擎上下文判断。
# 固定值 / 参数候选
- 无固定副类型候选。
# 语义
- 伤害反弹（原版的老兵的水晶盾）
## 存档数字 ID 与 amount 默认分类
- 存档 `stat_type` 数字 ID：`46`。
- `amount` 正值：增益；负值：减益；零值：减益。
- 这是默认增益/减益分类，不直接说明效果对游戏玩家有益或有害；Buff 型 DOT 的分类边界见[完整数字 ID 与 amount 分类表](../stat_type_amount_classification.md)。
# 作用范围
- `.buff_type damage_reflect_percent` 与 buffs.json 的 `"stat_type":"damage_reflect_percent"` 对应。
# 引擎行为（重要）
- 反伤也是一种真伤，以反伤 Buff 承载者实际损失生命为计算基础；不能笼统说所有对象的溢出伤害均不计入。
- 英雄作为反伤 Buff 承载者，受到怪物直伤时，降到0生命后的溢出量不计入反伤。
- 怪物作为反伤 Buff 承载者，受到英雄直伤时，因当前生命可以进入负数，该部分生命损失计入反伤，因此英雄可能承受看似过量的反伤。
- 依据迂回表第10条P447-P449/X496-X498及第11条P455-P460/X505-X511的后续纠正，当前用户于2026-11-02确认同步修正。仅覆盖以上两条直伤路径，不外推DOT、地图伤害或其他调用；本轮未新增实机测试。详见 Mechanics/59-反伤与生命溢出边界.md。
- 当前用户于2026-11-02澄清：谁掉血吃谁身上的易伤。初次伤害看承载反伤Buff者的易伤，反伤看承受反伤的原攻击者的易伤；不能对已确定的失血量再次乘承载者易伤。
- 易伤加成+1000%为11倍。已确定失血50、反伤100%、原攻击者+1000%易伤且无其他修正时，推导反伤550；原表500例不采为现行公式，非本轮实机测试。
# 常见错误
- 百分比型 amount 忘记使用小数（例如 30% 常写作 `0.3`）。
- 固定加减与倍率乘除顺序不同，极端负值可能出现反向增长等异常结果。
- `stat_sub_type` 缺失、误拼或错误地填写了不属于该主类型的值。
