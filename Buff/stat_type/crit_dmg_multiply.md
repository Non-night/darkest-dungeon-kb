# 语义
暴击伤害独立乘区：在固定暴伤加入后乘(1＋百分比暴伤增减)，早于全局暴击倍率及目标易伤。
# 作用范围
Buff定义；按实际施术者/持有者上下文核对。
# 引擎行为（重要）
- 新版功能文档2026-11-05；Sources/modding_update_20261105_remaining.json
- 官方文档B066–B067及后续社区实测公式：普通百分比伤害之后加固定暴伤，再乘新暴伤独立乘区，然后乘全局暴击倍率及目标易伤。来源：Sources/crit_damage_formula_test_20261105.json。
- 未提供新增存档数字ID或默认amount增减益分类。
- 知识库编写者提供的2026-11-05后续社区实测：暴击伤害按 [(基础最大伤害×伤害修正＋固定值伤害增减)×(1＋百分比伤害增减)＋固定值暴击伤害增减]×(1＋百分比暴击伤害增减)×全局暴击伤害倍率×(1＋目标身上的易伤) 计算。crit_dmg_add在普通百分比伤害区之后加入，再乘crit_dmg_multiply对应的独立乘区，随后乘全局暴击伤害倍率，最后乘目标易伤。两种新增暴伤修正均早于全局暴击倍率，与官方before Crit’s damage multiplier一致。固定暴伤类似damage_high固定加伤，但不吃旧damage_high的mult乘算／普通百分比增伤区；不可直接当作combat_stat_add的damage_high的完全替代。具体取整及公式未展开的其他修正不由本次测试补齐。 玩家说明：固定暴伤+10不是暴击倍率增加10个百分点。全局暴击倍率1.5、新百分比暴伤及目标易伤均为0时，+10固定暴伤带来15点伤害增量；有新百分比暴伤时该增量还要乘(1＋新百分比暴伤)，有易伤时也要乘易伤区。全局暴击倍率从150%等效放大到200%时，新百分比暴伤增量为1/3，约+33.33%（若以Buff amount表达则约0.3333）；133.33%是总乘数的百分数表示，不是额外增加133.33%。聊天中的其他游戏和WoW对比仅作理解背景，不收录为这些游戏的机制事实。 来源：Sources/crit_damage_formula_test_20261105.json。
