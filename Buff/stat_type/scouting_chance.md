scouting_chance
# 分类
Buff `stat_type`
# 参数类型
固定字符串；配套 `amount` 为数值，`stat_sub_type` 为字符串。
# 参数约束
- 该类型没有副类型；JSON 中字段仍必须存在，并写为空字符串 `""`。
- 只能使用通用型（条件型）rule；不能在战斗过程中瞬时生效。
# 固定值 / 参数候选
- 无固定副类型候选。
# 语义
- 提高队伍的侦查概率（百分比）。
## 存档数字 ID 与 amount 默认分类
- 存档 `stat_type` 数字 ID：`19`。
- `amount` 正值：增益；负值：减益；零值：减益。
- 这是默认增益/减益分类，不直接说明效果对游戏玩家有益或有害；Buff 型 DOT 的分类边界见[完整数字 ID 与 amount 分类表](../stat_type_amount_classification.md)。
# 作用范围
- `.buff_type scouting_chance` 与 buffs.json 的 `"stat_type":"scouting_chance"` 对应。
# 引擎行为（重要）
- 这是队伍级属性：队伍内所有英雄提供的所有 `scouting_chance` 修正相互加算。例如英雄 A 提供 `+10%`、英雄 B 提供 `+25%`，队伍最终获得 `+35%` 侦查概率。
- 队伍侦查概率由基础值与各来源修正共同计算。水月测试（当前用户2026-11-08转述）中出发面板0%仍非必不侦查，实际概率疑似有大于0的下限；具体下限及公式未确认，旧0%至100%确定截断说法退出当前结论。基础值默认数值仍未确认。
- 同一测试中，饰品任务开始扳机给予正极大侦查概率不能保证入本侦查，饰品静态+100%则测试中必定侦查。按当前用户给出的时序结论，饰品任务开始扳机晚于首次入本侦查检查；限该场景，不外推所有后续房间。见Sources/scouting_entry_timing_20261108.json及Mechanics/50-侦查与陷阱.md。
- 已知侦查视觉效果会在进入副本后首次切换到地图 UI 时，以及进入房间且当前 UI 面板选择地图时出现；概率判定的精确内部时点尚未确认，不能直接与演出时点画等号。
- 侦查分为小侦查与大侦查（也称侦查暴击）；大侦查范围更大，常规地图的秘门只能由大侦查发现。两者的具体概率、范围和升级判定公式尚未确认。
# 常见错误
- 百分比型 amount 忘记使用小数（例如 30% 常写作 `0.3`）。
- 固定加减与倍率乘除顺序不同，极端负值可能出现反向增长等异常结果。
- `stat_sub_type` 缺失、误拼或错误地填写了不属于该主类型的值。
# 代码案例
```json
{"stat_type":"scouting_chance","stat_sub_type":"","amount":0.1}
```
