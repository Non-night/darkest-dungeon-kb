# 恐惧、流血、腐蚀的解除控制

恐惧 DOT 可以通过特定 Buff 源类型实现无法被常规解除；同一办法对流血和腐蚀目前无效。流血与腐蚀只能通过控制对应治疗率/解除率的增减益，统一决定是否允许解除：一旦允许，绷带、解毒剂等常规解除会移除所有源类型的对应 DOT，。负量 DOT 现可存在，最终负持续时间不可存在；存在性不自动证明所有解除行为，见[负数 DOT 当前边界](66-负数DOT与不可治愈边界.md)。

该结论是对解除路径的限制，不是说所有 DOT 都共享同一清除规则。设计需要“仅禁止某个来源”或“不可被转移/偷取”时，必须另查具体源类型、转移 Effect 和善后方案。
