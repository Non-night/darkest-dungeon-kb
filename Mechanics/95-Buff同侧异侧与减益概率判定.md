## 同侧与异侧的统一规则

对由 Effect 施加的常规 Buff 型效果，减益施加率与减益抗性作为一对修正处理。无论 Buff 显示为增益还是减益，这里的同侧、异侧看 Effect 最终指向，结合施术者和最终受术者的关系以及目标参数的特殊语义判定，不按 Buff 数值正负决定是否过抗。

| 调用关系 | 施术者减益施加率 | 目标减益抗性 | 概率处理 |
|---|---|---|---|
| 实际同侧的常规 Buff | 不参与 | 不参与 | 基础 `.chance` 不受这两项修正 |
| 实际异侧的常规 Buff，如跨侧 `target`、`target_group` | 参与 | 参与 | 基础 `.chance` 加对应施加率、减对应抗性 |
| `target_enemy_group`、`target_group_other` 或 `target_enemy_rank` 的 Buff | 不参与 | 不参与 | 即使实际跨侧，也按同侧处理 |

同侧时，若没有其他专门概率修正，基础 `.chance` 就是该环节的施加成功率；达到或超过100%时该概率判定必成。此结论不绕过命中门、死亡门、目标合法性、Rule 或其他生效条件，也不代替暴击概率修正、`.keyStatus`、`.skill_instant true`、`.monsterType` 等字段各自的特殊规则。相关概率边界见[专题03](03-chance与抗性.md)。

先按调用方提供的目标和 `.target` 映射求出最终指向，再判断同侧/异侧，最后核对是否命中特例。不能把 `target` 系目标一概视为异侧：例如友方技能引用 `.target target` 的 Effect，最终目标是同侧英雄，其 Buff 不计算减益施加率及减益抗性；`target_group` 在友方技能中指向同侧全体时同理。相同参数用于进攻技能并最终指向异侧时，才按普通跨侧过抗。当前用户2026-11-02明确澄清这一调用情形。

## 指向异侧仍按同侧处理的 target 特例

这里仅列特例；常规同侧按最终指向判断，无须逐个列举自身或友方目标参数。

| `.target` 参数 | 实际选择范围 | Buff 概率性质与证据状态 |
|---|---|---|
| `target_enemy_group` | 技能目标所在一侧的对面全体；英雄友方技能通常指向怪物全体，英雄进攻技能通常指向英雄全体 | 已有资料确认：即使指向异侧，也不计算减益施加率及减益抗性 |
| `target_group_other` | 目标所在一侧除目标本身以外的其他单位 | 已有资料确认：即使指向异侧，也不计算减益施加率及减益抗性 |
| `target_enemy_rank` | 由 `.clear_rank_target` 指定的敌方站位目标 | 当前用户2026-11-02明确补充：即使指向异侧也视为同侧，减益施加率及减益抗性不参与 |
| `target_enemy_random` | 随机怪物目标 | 当前用户2026-11-02表示“好像也视为同侧”；属于待确认线索，不能作为已确认的过抗或不过抗依据 |

`target`、`target_group` 等常规目标按最终指向判断，跨侧时正常过抗。上表不声称穷尽特例；不得由名称猜测其他参数的侧别性质。`global` 在主术语表表示环境，`this_trinket` 指向发起饰品，均不能直接视作普通单位侧别的证据。目标交换、spawn 定向或其他调用链仍须先核对最终指向。特殊群体目标的正负抵消模拟、图标和清理代价见[专题64](64-特殊群体目标与减益抗性.md)。

## DOT 与连续 set 的边界

普通 Effect 型流血、腐蚀、眩晕、位移、疾病等具有各自施加率与抗性的效果，不因同侧或上述已确认特殊目标就免除其自身抗性。Buff 型 DOT 则按 Buff 施加规则处理，不能只看到“流血”名称便套用普通流血 Effect 的施加率与抗性；精确类型见[hp_dot_bleed](../Buff/stat_type/hp_dot_bleed.md)。负数 DOT 能否施加是另一问题，现行限制见[专题66](66-负数DOT与不可治愈边界.md)。

同一怪物连续 set 的 spawn 从第二次 set 起另有异常：原本跨侧施加给英雄的 Buff 按同侧处理，减益施加率及抗性不参与。该异常不是新增 `.target` 参数，不推广其他调用方或独立抗性系统；定向失效的精确起始次数另论，见[专题28](28-spawn、生命反馈与size0执行链.md)。

## force_resist_type的显式覆盖

知识库编写者2026-11-05实测确认：无论Effect原本是否需要过抗，.force_resist_type均改用指定类型对应的施术者施加率和受术者抗性；替代原判定，不是追加第二次过抗。指定poison时仅看腐蚀施加率与腐蚀抗性，减益施加率与减益抗性完全不参与。该明确结论也覆盖原本按同侧处理、不经过减益抗性的效果；不再保留原先的两个选择疑问。
