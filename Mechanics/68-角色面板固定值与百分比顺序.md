# 角色面板固定值与百分比顺序

角色面板属性的算法与治疗相反：先计算固定值加减，再计算百分比乘除。抽象形式为：

```text
最终值 = (原始值 + 固定值修正) × (1 + 百分比修正)
```

因此，固定值减益若把中间结果压成负数，后续负百分比可能产生负负得正的逆增长。例如基础攻击力 9，先施加 `-500` 固定值、再施加 `-500%` 百分比，会得到 `(-491) × (-4) = 1964`。面板为 0 也不代表内部参与运算的实际值为 0，最大生命等负值面板必须单独警惕。

该顺序主要适用于伤害、生命及其他确实同时存在固定与百分比修正的属性；精准、暴击、闪避、防御、速度等属性的常见修正形式不同，不能从本例擅自外推所有字段。负向倍率低于 `-100%` 的面板属性应视为高风险设计。
