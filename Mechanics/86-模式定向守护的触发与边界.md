模式定义可使用 `.always_guard_actor_base_class_ids` 指定至多四个英雄职业 ID 或怪物大类 ID；每个 ID 最多 64 字符。它依附于当前模式，官方实例包括宫廷 DLC 雕像盾牌：

```darkest
mode: .id onscreen .is_raid_default true .always_guard_actor_base_class_ids statue_head
```

## “带出战斗”的术语含义

知识库编写者确认（2026-09-20）：本知识库中说某个模式“可以带出战斗”，专指该 `mode:` 定义写有 `.is_raid_default true`。这是术语约定，不是对所有模式切换、`.set_mode` 或战斗开始 Effect 的泛化描述。

```darkest
mode: .id example_mode .is_raid_default true
```

是否还需要配套战斗外动画、模型、技能或其他模式字段，仍按英雄/怪物侧和具体调用链分别检查；“带出战斗”只确认这个 `.is_raid_default true` 条件。

## 社区实测结论

- 单位**进入该模式时**，会对指定同侧目标施加定向守护；维持在该模式时不每回合自动刷新。若守护后来被清除，必须先离开该模式再重新进入，才会再次施加。
- 它无视被守护目标的“无法被守护”状态；不要把常规 `guard_blocked` 的预期限制套用到此机制。
- 它不能跨侧守护：英雄只能以此守护英雄，怪物只能以此守护怪物。

## 创作边界

该字段的目标是 `actor_base_class`／怪物大类 ID，不是带 A/B/C 差分的实体名。模式 ID、目标 ID、目标是否同侧，以及需要何时通过模式切换刷新，都必须在 Info 定义中逐项核验。上述行为来自社区实测；多目标同时命中时的守护优先级、目标不存在或同名大类的完整边界尚未确认。
