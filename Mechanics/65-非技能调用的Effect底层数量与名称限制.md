当前用户2026-11-02澄清：`spawn: .effects` 的 4 个 Effect ID 是理论上限，不保证四项实际都完整执行；因为可能发生截断，绝大多数情况推荐每行只写 1 个或 2 个 Effect ID，更多调用采用分行。1–2 个是降低截断风险的创作建议，不是“超过两个必定不执行”的硬上限，也不保证如此便绝无截断。具体截断触发条件和临界值尚未确认，不补造原因。此数量边界限于 spawn，不推广到所有非技能调用方。

原表第15条 P495–P497/X551–X553 的“两条硬上限、每行只能两个”已经划删除线，不作为现行结论；P498/X554 的理论四项须结合上述实际建议。该澄清不是本轮新增实机测试。另保留已确认边界：**被 spawn 引用的 Effect 名称/ID 不得超过 31 个字符**；生成时按 31 字符保守限制处理。

### spawn Effect ID 的长度计数边界

当前用户的实测工作口径是：ID 中的空格计入长度，调用代码外侧用于语法的引号不计入名称长度；引擎底层究竟是在解析前还是解析后计数、引号是否在某些写法中参与计数，仍未专项确认。因此不要用引号“凑长度”，也不要依赖接近 31 的临界值；实际创作应使用短的 ASCII 字母、数字和下划线 ID，并尽量不含空格。

`spawn` 所执行的 Effect ID 过长会红字报错找不到 Effect；该名称长度限制是 spawn/类似非技能调用的特例，不能推广到技能 Effect。道具名称过长会导致音效、光效等附属条目找不到；就这条名称长度问题而言，道具自身 Effect 执行不受影响。当前用户2026-11-02认为原表第15条 P500/X556 此结论正确，并推测成因是单行截断。成因仅为当前用户推测，尚未确认；不据此补造具体名称长度阈值，也不保证任意报错都不影响 Effect。本轮没有新增实机测试。

以上结论区分了字段静态资料中的 64 字符记录和当前用户对 spawn 的 31 字符实测边界；对未专项确认的其他非技能调用方，不擅自推广统一上限。
