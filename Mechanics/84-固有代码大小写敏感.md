## 已确认范围

固有代码必须按已知形式区分大小写；以 Buff 的 `stat_type` 为例，使用知识库和原版实例中的小写形式，混入大写后不能被正确识别。

```json
{
  "stat_type": "damage_received_percent"
}
```

`Damage_Received_Percent` 等大小写变体不能作为等价写法。字段名、ID 和本地化 Entry 的大小写规则不能由本条一并推出。

## 未知边界

当前只确认具体固有代码案例，不把它推广为所有未知字段都必然大小写敏感。遇到未收录的字段，应先查对应 Header、原版实例或专项实测，再决定可用大小写。
