## 任务专属 `activate` / `gather` 奇物

任务目标为 `activate` 或 `gather` 时，目标使用的是任务专属奇物，不是常规互动奇物。迂回表第99条 P1568/X1948 记载，这类任务奇物不能写入 `*_curio_props.csv` 或 `*_curio_type_library.csv`；目标奇物、`activate` 后的奖励以及 `gather` 获得的任务道具由任务 goal 定义决定，不由常规奇物定义文件负责。原表还记录，把这类任务奇物错误写入常规奇物定义文件，在相关任务刷新时可能导致崩溃；此处保留该场景边界，不补造其他 goal 字段或崩溃条件。

固定本地图中，任务奇物位置使用 `room;quest_curio` 之类的 `quest_curio` 声明，不使用常规奇物的 `curio=` 引用。原版猩红庭院 `cc_map_intro.csv` 已核对到房间和走廊两类实例：`:4`、`:8` 与 `:19` 包含 `c;quest_curio` 或 `room;quest_curio`。因此，`quest_curio` 可以出现在走廊；迂回表第99条 P1569–P1570/X1950–X1952 关于走廊任务奇物的观察与该原版地图实例一致。这里只确认入口字段和位置观察，不把原表示例扩展成任意地图格式或任务系统的完整实现规则。

本节依据原版地图实例与迂回表第99条，当前用户于2026-11-04确认补入；未新增实机测试。

## 队伍侦查概率
- `scouting_chance` 是队伍级百分比属性。队伍中所有英雄提供的所有侦查概率修正相互加算，而不是只读取某一名英雄或取最高值。
- 例如英雄 A 持有 `scouting_chance +10%`，英雄 B 持有 `scouting_chance +25%`，则队伍总侦查概率获得 `+35%` 修正。
- 基础侦查概率与上述修正共同参与计算；出发面板显示0%不保证实际必不侦查。2026-11-08收录的水月测试使实际概率下限存疑，疑似存在大于0的下限；具体值与公式未知，不再将“最终截断在0%至100%”作为已确认完整边界。
- 基础侦查概率应该定义在全局规则中，但当前尚未核实其默认数值和准确字段。

## 入本侦查与饰品任务开始扳机（水月测试）

当前用户于2026-11-08转述水月测试并要求记录，原始表述与证据分层见 `Sources/scouting_entry_timing_20261108.json`；这是社区实测转述，不是本轮 Agent 实机测试，测试日期、次数及完整文件未提供。

1. 饰品静态 Buff 为侦查概率 -25%，使出发面板显示0%；同一测试中饰品在任务开始时给英雄施加正极大侦查概率。入本结果既无法必定侦查，也无法必定不侦查。
2. 对照为直接把侦查概率 +100% 写入饰品静态 Buff，测试中入本必定侦查。

据当前用户给出的时序结论：**饰品任务开始扳机晚于进入副本时的首次侦查检查，靠该扳机新增的侦查 Buff 赶不上该次检查；要干涉该次检查，测试支持使用进入前已有效的饰品静态侦查 Buff。**结论限定于该入本场景，不推导所有任务开始调用源、后续房间检查或引擎精确函数／帧。

另一个结论保留为**推断/待验证**：侦查实际概率疑似有大于0的下限，面板0%不能作为必不侦查保证。此测试没有确定具体下限或公式，也不能只凭面板与结果差异就宣称已经证明了硬下限的内部实现；此次不重新认证概率上限或基础侦查值。不得把这个存疑项自动变成检查器的数值报错规则。

## 地图演出与判定时点
已知侦查的视觉效果会在以下节点出现：

- 进入副本后首次切换到地图 UI；
- 进入一个房间时，当前 UI 面板正选择地图。

角色要离开初始房间或其他房间前，本来也必须切换到地图 UI 并选择路径。上述节点是已观察到的演出时点，不足以证明随机概率恰好在同一帧或同一内部函数中判定；精确时刻仍未知。前节仅补充首次入本检查早于饰品任务开始扳机的相对时序，不把侦查演出与内部判定画等号。

## 小侦查与大侦查
- 侦查分为小侦查和大侦查；大侦查有时也称“侦查暴击”。
- 大侦查的揭示范围大于小侦查。
- 常规地图中的秘门只能被大侦查发现。
- 原版 `shared/rules.json:430–431` 的 `scouting_crit_success` 为 `0.50`，`scouting_chance_base` 为 `0.25`。是否在普通侦查成功后独立掷骰、两者的准确范围及与总侦查概率的计算关系，尚未确认。见[原版副本专题](101-原版副本探索、扎营夜袭与出本结算.md)。

## 与陷阱的关系
陷阱默认不可见，房间侦查成功后才会显示。发现陷阱与英雄接触陷阱时的解除／闪避判定是两个不同阶段：后者还会综合英雄陷阱抗性、陷阱是否已被侦查、地图等级和全局规则等因素，不能把 `scouting_chance` 当作陷阱抗性。
