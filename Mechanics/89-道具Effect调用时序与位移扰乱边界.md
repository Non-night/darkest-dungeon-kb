## 调用时序

道具 Effect 不属于技能释放后的 `AWR → queue false → queue true` 技能时序。道具在战斗外使用时直接在战斗外调用；在战斗内使用时，于技能释放前、由道具调用方自身的调用流程执行。因此不能把技能 Effect 的 `queue`/`AWR` 先后模型直接套到道具上。道具 Effect 中即使写入这些字段，也不能据此保证其在某个技能时序层执行；具体调用顺序应以道具套娃、怪癖改道具效果和当前使用场景分别核验。

## 位移与扰乱

社区实测表明，真实道具和虚拟道具均不能触发以下单体 Effect：

- `.push`（推）
- `.pull`（拉）
- `.shuffletarget`（单体扰乱）

它们可以触发：

- `.shuffleparty`（群体扰乱）
- `.instant_shuffle`（瞬间扰乱）
- `.dotShuffle`（延迟扰乱）

英雄播放被位移台词不代表道具中的推/拉已经改变站位。该结论只覆盖道具调用方，不外推到技能、spawn、ActorDot 或 `act_out`。

## 证据与未知

以上为迂回表 2026-08-04 版本的调用方实测；道具在不同套娃层、不同目标映射和不同战斗状态下的其他 Effect 限制仍未完整测试。
