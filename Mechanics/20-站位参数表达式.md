站位以数字表示。对于常规单位，最多有一号位至四号位；多个站位数字可以写在同一个表达式中，并可使用前缀改变选择方式。

| 表达式 | 含义 |
|---|---|
| `1` | 一号位 |
| `12` | 一号位或二号位构成的站位范围 |
| `1234` | 一号位至四号位构成的站位范围 |
| `~12` | 同时选择一号位和二号位 |
| `?12` | 从一号位和二号位中随机选择一个 |
| `@12` | 友方一号位或二号位构成的站位范围 |

## AOE 判断
在 `*.info.darkest` 的技能定义中：

- `12`、`1234` 和 `@12` 表示可选范围，本身不是 AOE。
- `~12` 才表示同时选择列出的多个站位。
- `?12` 表示随机选择一个列出的站位。

不同字段对前缀的支持以及对站位范围的解释可能不同，不能把 info 技能的规则无条件套用到所有字段。

## 设计稿中的圆点站位标记

设计稿有时不直接填写数字，而是用四个圆点表示四个常规站位，例如：

```text
●●●○
```

圆点必须按其所代表的阵营一侧进行换算，而不能机械地始终从左到右记作 `1234`：

- **英雄侧站位通常从左到右排列为 `4 3 2 1`**。因此，英雄技能的启动站位标成 `●●●○` 时，表示可从四、三、二号位启动，代码为 `.launch 432`。
- **怪物侧站位通常从左到右排列为 `1 2 3 4`**。因此，英雄攻击技能的敌方目标标成 `●●●○` 时，表示可选择怪物一、二、三号位，代码为 `.target 123`。
- 其他圆点组合以同一排列规律换算。例如英雄启动站位最右一个圆点为实心时表示一号位；敌方怪物目标最左一个圆点为实心时表示一号位。
- 若英雄技能选择的是友方英雄目标，圆点仍应按英雄侧的 `4321` 排列理解，而不是按敌方目标的 `1234` 排列。

上述排列是英雄设计稿的通常约定。**怪物设计稿的圆点方向不作默认推定**：作者可能按怪物自身视角、玩家屏幕视角或其他模板排列。若用户用圆点描述怪物技能的启动站位或目标站位，必须先确认四个圆点从左到右分别对应哪些数字，再生成 `.launch` 或 `.target`。

## `.clear_rank_target`
- 参数是一个站位表达式，属于怪物侧 AI 的 `rank_target` 特殊机制。
- 当前资料记载该字段接受 `@` 与 `~`，不接受 `?`。
- 当前尚不确定 `12` 与 `@12` 在本字段中是否完全沿用 info 技能的“可选范围、非 AOE”语义。
